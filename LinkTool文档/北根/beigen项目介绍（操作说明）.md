# LinkTool 新进展｜从桌面插件到网页平台，我们把灵图带到了北根村

**北根灵图 LinkTool｜自然语言交互 · 多智能体分析 · 三维地图展示**

北根灵图是由华南农业大学地理信息科学专业 LinkTool（灵图）团队开发的乡村地理信息智能分析平台。

平台以肇庆市北根村为应用示范，将村庄地理数据、专业分析工具与三维地图连接起来，支持从需求理解、任务规划，到空间计算、专题制图和报告生成的完整流程。

它的核心思路是：**大模型理解需求，智能体组织执行，GIS 工具完成计算。**

围绕这条流程，我们把数据探索、任务规划、地理处理、数据预览、图件生成和报告撰写组织为六类智能体，让用户提出的问题能够逐步落实为地图、统计与报告。

上次和大家见面时，LinkTool 还是一个基于 ArcGIS Pro 的拓展插件。经过这段时间的打磨，我们将它升级到了 Web 端，并在北根村开展了实际应用。

**无需安装专业软件，打开浏览器，就能用日常对话查询村庄、分析数据。**

这就是我们这次带来的项目——**基于多智能体架构的智慧乡村数字基座（北根灵图）**。

## 走出软件，智入乡村

**村里有数据，为什么还是用不起来？**

众所周知，GIS 分析离不开数据。土地调查、村庄规划，给村里留下了不少资料。

但要算一片区域、画一张地图，往往还得请专业人员打开软件，一步步处理。

而村干部和农业经营者关心的问题，其实很具体：

“村里水田都在哪里？”

“现有的垃圾收集点是否方便居民处理垃圾？”

我们想让这些问题，可以直接交给灵图。

**大家说需求，灵图做计算、出成果。**

## 三栏交互，轻松上手

那么有人要问了，这次 Web 端的灵图平台到底长什么样？普通人又该怎么用呢？

打开网页，跟着下面四步操作。

### Step 01｜进入工作台

- 打开[北根灵图](https://beigen.peterzhong.site/)，登录系统。
- 点击顶部导航【地图】，进入三栏工作台。
- 认准三个位置：**左边管图层，中间看地图，右边提需求。**

平台主界面展示

### Step 02｜逛实景、查家底

- **逛村庄：** 在中间地图拖拽、缩放、旋转，查看由 3 厘米分辨率航测数据构建的北根村实景三维。
- **查一块地：** 点击左侧对应图层名称，再点击地图中的地块，查看名称、类别等信息。
- **查整张表：** 鼠标移到左侧图层条目，点击【属性表】图标，完整表格就在地图底部展开。
- **叠加自己的数据：** 点击右侧输入框上方的【上传 GeoJSON/JSON 数据】，选择文件，在地图中预览。

地图浏览与属性表展示

### Step 03｜提需求、看过程

- 在右侧【智能体对话】输入框，用大白话写下需求。例如：“统计北根村各类耕地面积，并画出分布图。”
- 按 **Ctrl+Enter** 发送。系统询问距离、范围等条件时，按提示补充。
- 点击右上方【工具调用】，选择任务条目，查看执行步骤、工具参数与运行状态。

**六类智能体分工：找数据、拟方案、做计算、预览数据、制作图件、撰写报告。**

智能体对话与工具调用展示

### Step 04｜调样式、拿成果

- 用左侧图层开关控制显示，拖动图层左边的排序手柄，调整上下叠放顺序。
- 点击左侧【颜色指示】，选择图层，查看系统自动配好的分类颜色和图例。
- 切回右侧【智能体对话】，在对话下方找到【结果文件】，点击文件名打开专题图或报告预览。
- 点击预览窗口中的【下载】，把成果保存到电脑。

**从提出需求，到查看地图、下载成果，四步就能找到对应入口。**

图例与结果文件展示

## 北根实战，灵图答卷

入口找到了，接下来能做什么？

我们以北根村为例，做了两项分析：一项查清耕地家底，一项寻找垃圾收集点的服务盲区。

### 查清农田，先算一笔土地账

村里有多少水田、旱地？分布在哪里？把这个问题直接发给灵图。

**【我们只需输入一句话】**

> 请查询北根村耕地分布，按水田、水浇地和旱地分别统计数量与面积，并生成分类分布图。

**【灵图智能体自动干了什么】**

调取土地利用数据 → 筛选三类耕地、计算面积 → 分类配色制图 → 汇总统计成果。

农田资源统计过程展示

**【最终拿到的结果】**

**北根村耕地总面积：1,284,549.73 平方米。**

- **水田 110 块**，面积 1,186,048.03 平方米，占耕地总面积的 **92.33%**；
- **水浇地 29 块**，面积 48,050.45 平方米，占比 **3.74%**；
- **旱地 11 块**，面积 50,451.25 平方米，占比 **3.93%**。

耕地分布成果展示

**水田占耕地总面积的 92.33%，是北根村的主要耕地类型。**

数字看规模，地图看位置。分类分布图和统计成果，可以直接用于梳理村里的耕地资源，了解不同地块的分布与连片情况。

### 查看覆盖，再找设施补点方向

村里有垃圾收集点，但哪些居民区还没有被服务范围覆盖？这次，我们让灵图把设施位置和村屋分布放在一起分析。

**【我们只需输入一句话】**

> 请结合北根村村屋分布，分析垃圾收集点的服务覆盖情况，找出未覆盖区域，并给出设施增设建议。

**【灵图智能体自动干了什么】**

调取垃圾点、村屋和村界数据 → 生成缓冲范围、叠加计算 → 配色制图、标出盲区 → 整理分析报告与优化建议。

垃圾收集点分析过程展示

**【最终拿到的结果】**

- 围绕 **6 个垃圾收集点**展开覆盖分析。
- 展示 **50 米、100 米范围的覆盖对比**。
- 形成 **200 米缓冲范围专题图**，对照设施与居民区的位置。

垃圾收集点服务范围展示

**服务覆盖薄弱区域主要位于村庄西南部、西北部边缘，以及丘陵坡地的零散居民点。**

最终，我们拿到了**交互式网页地图、统计数据和分析报告**，以及近期、中期、长期的优化建议。

打开地图，就能找到需要重点走访的区域；翻开报告，就能查看覆盖情况和补点思路。

## 智能协作，技术支撑

从一句话到一张地图、一份报告，背后有哪些技术在配合？

我们围绕大模型搭建了一套智能体执行机制（Harness），把任务分工、工具调用、知识检索、过程记录和文件保护连接起来，让每一步分析都有对应的执行方式。

### 平台核心特性

| 核心特性 | 实现方式 |
| --- | --- |
| **多智能体分工** | 六类智能体分别承担数据探索、任务规划、地理处理、数据预览、图件生成与报告撰写 |
| **按任务组织流程** | 根据需求与数据安排分析步骤，通过连续对话补充范围、距离和成果要求 |
| **专业工具调用** | 通过 MCP 工具接入协议，调用数据查询、缓冲区分析、空间叠加、统计等工具 |
| **领域知识检索** | 按需求查找相关规范和案例，为分析方案与报告编写提供参考 |
| **地图自动表达** | 分析结果推送至三维地图，支持统一配色、按类别区分颜色及按数值分级显示 |
| **任务过程可查** | 保留工具参数、运行状态、返回结果与历史对话，支持展开查看执行记录 |
| **数据分区保护** | 原始数据只读保存，过程文件与成果分别存储；修改输入数据前先建立工作副本 |

### 主要技术栈

| 技术模块 | 采用技术与作用 |
| --- | --- |
| **网页交互** | Vue 3、Element Plus、Pinia：构建三栏工作台，管理对话、图层与页面状态 |
| **三维地图** | Cesium.js：展示实景三维模型、影像与分析图层，提供地图浏览和属性查询 |
| **业务与实时通信** | Django、Django REST Framework、Channels：处理业务请求，通过 WebSocket 推送对话和分析事件 |
| **智能体执行** | Claude Agent SDK、MCP、Agent Skills、Hooks：组织智能体任务、接入工具、加载分析技能并执行操作检查 |
| **空间分析与制图** | GeoPandas、Rasterio、WhiteboxTools、GDAL、QGIS：处理矢量与栅格数据，执行空间计算并生成专题图 |
| **知识检索** | SQLite-vec、Qwen 文本嵌入与重排序模型：根据问题检索相关资料，并对候选内容排序 |
| **业务数据存储** | PostgreSQL / SQLite：保存用户、历史对话、任务与图层等业务记录 |
