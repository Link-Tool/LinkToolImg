# 江屯镇耕地质量等级评价任务计划

## 1. Task Goal
根据《广东省第三次全国土壤普查县级耕地质量等级评价技术细则（试行稿）》，对肇庆市广宁县江屯镇现状耕地进行耕地质量等级评价，形成符合技术细则目录规范的成果（数据、图件、报告）。

**评价分区**：长江中下游区 → 南岭丘陵山地林农区（广宁县归属，附件1）

## 4. Output Field Naming Convention（附件11 PJDYT 属性结构）
评价指标原始值字段：地形部位DXBW、有效土层厚度YXTCHD(Float)、质地构型ZDGX、耕层质地GCZD、土壤容重TRRZ(Float)、有机质YJZ(Float)、有效磷YXL(Float)、速效钾SXJ(Float)、水资源条件SZYTJ、排水能力PSNL、耕层厚度GCHD(Float)、酸碱度SJD(Float)。

权重字段（后缀QZ）：DXBWQZ、YXTCHDQZ、ZDGXQZ、GCZDQZ、TRRZQZ、YJZQZ、YXLQZ、SXJQZ、SZYTJQZ、PSNLQZ、GCHDQZ、SJDQZ（Float 8,4）。

隶属度字段（后缀LSD）：DXBWLSD、YXTCHDLSD、ZDGXLSD、GCZDLSD、TRRZLSD、YJZLSD、YXLLSD、SXJLSD、SZYTJLSD、PSNLLSD、GCHDLSD、SJDLSD（Float 8,4）。

结果字段：综合指数ZHZS(Float 10,4)、质量等级ZLDJ(Int)、年度粮食产能水平NDLSCN、单季粮食产能水平DJLSCN、年度粮食生产潜力NDSCQL（产能字段本次跳过，保留字段留空）。

标识/行政区字段：BSM、DYBH、XQMC、ZMC、DLBM、DLMC、TBMJ、GDPCMJ、STLMC、SYLMC、STSMC、STZMC。
